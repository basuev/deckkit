# Cyberpunk 2077 UI assets

These two archives contain modified UI definitions derived from a legitimately
installed copy of Cyberpunk 2077. Original game content remains the property
of CD PROJEKT RED. The repository's MIT license applies to our program code,
not to the original or derivative game resources in these archives.

This is an unofficial fan work and is not approved or endorsed by CD PROJEKT RED.
The archives are intended for use with Cyberpunk 2077 under the relevant game
EULA and [CD PROJEKT RED Fan Content Guidelines](https://www.cdprojektred.com/en/fan-content).

The archives contain ten UI resources. They contain no replacement font files,
DLLs, executable scripts, or content from the third-party font mods consulted
during development.
